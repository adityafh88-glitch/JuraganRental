# Naskah Musik Radio — Juragan Rental

Lagu ini diputar dari **radio di meja kasir** (Radio Juragan FM). Pemain bisa menyalakan, mematikan, dan mengganti lagu. Musik juga bisa dimatikan di HP → tab **Atur**.

## Cara membuat di ElevenLabs Music

1. Buka **ElevenLabs → Music**.
2. Salin teks di dalam kotak prompt di bawah, persis apa adanya. Jangan ikut menyalin nama file atau durasinya.
3. Atur durasi lewat ikon jam (tulisan **Auto**) sesuai durasi di judul. Semua prompt sudah memuat "no vocals", jadi lagunya tanpa vokal.
4. Buat 2–3 versi, pilih yang paling enak, lalu unduh sebagai MP3.
5. Ganti nama file sesuai judul lagunya (misalnya `MUS_Radio_1.mp3`), lalu kirim path-nya ke saya. Saya yang mengubah ke WAV dan memasukkannya ke Unreal.

> Sebelum dipakai di game yang dijual, cek di halaman paket ElevenLabs bahwa paketmu mengizinkan **pemakaian komersial** untuk musik.

Lagu yang belum ada dilewati otomatis. `MUS_Radio_1` saat ini berisi lagu sementara buatan sendiri dan akan tertimpa saat kamu mengirim versi ElevenLabs.

## Catatan arah musik

- **Volume rendah dan tidak ramai.** Pemain bisa main berjam-jam, jadi hindari drum keras, sirene, atau melodi yang terlalu menonjol.
- **Tanpa vokal.** Supaya tidak bertabrakan dengan celetukan pelanggan.
- **Jangan menyebut nama penyanyi atau judul lagu asli** di prompt, supaya aman hak cipta.
